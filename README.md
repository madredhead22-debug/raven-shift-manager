# אפליקציית ניהול משמרות - חנות 2 (Mobile-First)

אפליקציית ווב מודרנית, קלילה ומותאמת במיוחד למכשירי סמארטפון לניהול משמרות לא סדירות בחנות 2, שמירה על חלוקה שוויונית בין העובדים, התנדבות עצמאית, החלפות משמרות ויצירת הודעות וואטסאפ בלחיצה אחת.

---

## 🚀 הרצה מקומית

כדי להריץ את המערכת במחשב:
```bash
npm run dev
```
פתחו את הדפדפן בכתובת: **`http://localhost:3000`**

---

## 🔑 פרטי התחברות ברירת מחדל

1. **כניסת מנהל:**
   - לחצו על לשונית **"כניסת מנהל"**
   - קוד PIN: **`9999`**
2. **כניסת עובדים:**
   - בחרו שם עובד מתוך הרשימה (לדוגמה: "יוסי", "דניאל", "נועה", "שיר")
   - קוד PIN ראשוני: **`123456`**

---

## 📱 מסכים ויכולות עיקריות

### 1. דשבורד (Dashboard)
- **תקציר שבועי:** משמרות נדרשות, כמות משובצות ומשמרות פתוחות.
- **טבלת שוויון עובדים:** מדרג עובדים לפי כמות המשמרות שביצעו בחנות 2, עם סימון מי בראש התור לשיבוץ הבא.
- **כפתור שיבוץ אוטומטי שוויוני:** משבץ משמרות פתוחות לעובדים עם מונה המשמרות הנמוך ביותר.
- **כפתור קיזוז (נרמול נתונים):** מפחית את ערך המינימום מכל העובדים (מאפס את הנמוך ביותר ושומר על ההפרשים).
- **העתקת הודעות לוואטסאפ:**
  - הודעה על משמרות פתוחות להתנדבות.
  - סיכום שבועי מסודר של כל המשמרות והעובדים.

### 2. לוח שיבוץ שבועי (ראשון עד שבת)
- ניווט בין שבועות וטאבים לכל יום (ראשון–שבת).
- **למנהל:** פתיחת משמרת, עריכת שעות, עדכון תקן עובדים, שיבוץ ידני, וכפתור **"נמצא מחליף"** (מסיר עובד ללא חיוב במניין המשמרות).
- **לעובד:** התנדבות ישירה למשמרת פתוחה, בקשת חילוף (מסירה למאגר או החלפה ישירה מול עובד). עובד נשאר אחראי למשמרת עד שמישהו מאשר ולוקח אותה בפועל.

### 3. ניהול צוות (למנהל)
- הוספת עובד חדש בהזנת שם בלבד (מקבל אוטומטית PIN של `123456`).
- עריכת מונה משמרות ידנית במידת הצורך.
- איפוס קוד PIN ומחיקת עובד.
